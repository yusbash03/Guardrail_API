# API Contract

Base path: `/api/v1`. JSON (UTF-8), camelCase. Money = decimal string with 2 dp + `currency`. Timestamps = ISO 8601 UTC. IDs = UUID strings. Errors = ProblemDetails (ERROR_HANDLING.md). OpenAPI generated by Swashbuckle/`Microsoft.AspNetCore.OpenApi` at `/swagger` (non-production) and `/openapi/v1.json`.

**Auth:** `Authorization: Bearer <access token>` unless marked *anon*.
**Idempotency:** endpoints marked 🔁 require `Idempotency-Key` (8–100 chars). Same key + same body → stored response replayed; same key + different body → `422 IDEMPOTENCY_KEY_REUSED`. Keys expire after 24 h.
**Pagination:** `?page=1&pageSize=20` (max 100) → `{ "items": [], "page": 1, "pageSize": 20, "totalCount": 57 }`.
**Correlation:** `X-Correlation-Id` accepted/echoed.

## Auth

| Method | Path | Notes |
|---|---|---|
| POST | `/auth/register` *anon* | `{ email, password, displayName, timeZone }` → 201 `AuthResponse`; sets refresh cookie |
| POST | `/auth/login` *anon* | `{ email, password }` → 200 `AuthResponse`; sets refresh cookie |
| POST | `/auth/refresh` *anon (cookie)* | requires header `X-Guardrail-Client: web` → 200 `AuthResponse`, rotates cookie |
| POST | `/auth/logout` | revokes refresh token family, clears cookie → 204 |
| GET | `/me` | → `UserDto` |

```json
// AuthResponse
{ "accessToken": "eyJ…", "expiresAt": "2026-11-03T14:20:00Z",
  "user": { "id": "…", "email": "amara@example.com", "displayName": "Amara", "role": "USER" } }
```
Refresh cookie: `gr_rt`, `HttpOnly; Secure; SameSite=Strict; Path=/api/v1/auth; Max-Age=604800`.

## Policies

| Method | Path | Notes |
|---|---|---|
| GET | `/policies` | Current `PolicyDocument` (SPENDING_POLICY_ENGINE.md §1.1) |
| PUT | `/policies` | `{ expectedVersionNumber, changeSummary?, policy: PolicyDocument (without ids/versionNumber) }` → 200 new `PolicyDocument`; 409 `POLICY_VERSION_CONFLICT`; 422 `POLICY_INVALID` / `POLICY_MERCHANT_CONFLICT` |
| GET | `/policies/versions` | paginated `[{ versionNumber, policyVersionId, changeSummary, createdAt, snapshotHash }]` |
| GET | `/policies/versions/{versionNumber}` | `PolicyDocument` for that version |
| POST | `/policies/simulate` (P2) | `{ merchantId, items: [{productId, quantity}] }` → `PolicyDecision` (not persisted, no cart) |

```json

    "merchantRules": { "approvedMerchantIds": ["…","…"], "blockedMerchantIds": [], "newMerchantAction": "BLOCK" },

    "duplicatePurchase": null,
    "timeRestrictions": [],

```

## Rate limits (per user unless noted)

| Policy | Limit |
|---|---|
| `auth` (per IP) | 10 / min |
| `agent` | 20 turns / 10 min, 1 concurrent turn |
| `mutations` (carts, purchases, approvals, policies) | 60 / min |
| `approval-step-up` | 5 failed password attempts / 15 min |
| `reads` | 300 / min |
| `webhook` (per IP) | 120 / min |

Exceeded → `429` with `Retry-After`.
